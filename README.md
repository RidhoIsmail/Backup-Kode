# 🚀 Backup-Kode Competitive Programming

Selamat datang di repository **Backup-Kode** 👋  
Repository ini berisi kumpulan kode program, algoritma, dan rencananya berisi template Competitive Programming yang dapat digunakan untuk belajar maupun latihan.

---

## 📌 Cara Menjalankan Program

Kamu bisa mencoba program-program di repository ini menggunakan:

- 💻 Compiler C++ biasa
- 🌐 USACO IDE Online
- ⚡ IDE favorit lainnya seperti VS Code, Dev-C++, CodeBlocks, dll.

---

# 🌐 Menjalankan di USACO IDE

## 🔗 Buka Website USACO IDE

👉 https://ide.usaco.guide/

---

## 📋 Copy Kode Program

1. Buka folder program yang ingin dicoba
2. Salin (copy) seluruh kode program
3. Paste ke editor di USACO IDE
